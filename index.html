SimpleAudit

Lightweight AI safety auditing, local-first

A simple, extensible framework for multilingual auditing and red-teaming of AI systems via adversarial probing. Run open models locally — no APIs required.

Get started in one line

Two packages, minimal setup. pip installs SimpleAudit and you can audit a model in a few lines of Python.

terminal 
$ pip install -U simpleaudit

Audit a model in a few lines

Point the Target → Auditor → Judge pipeline at any model and run the built-in safety scenarios.

python 
from simpleaudit import ModelAuditor

auditor = ModelAuditor(
    model="hf.co/NbAiLab/borealis-4b-instruct-preview-gguf:BF16",
    provider="ollama",
    judge_model="gpt-4o",
    judge_provider="openai",
)

results = auditor.run("safety", max_turns=5, max_workers=10)
results.summary()
results.plot()

Local-first

Run open models locally via Ollama or vLLM — no APIs, no data leaves your machine by default.

Multilingual

Adversarial probing across languages and domains, with versioned scenario packs you can extend.

Minimal setup

Two packages, a clear Target → Auditor → Judge pipeline, and reproducible comparative scores.

What you can do

  • ✓ Audit any OpenAI-compatible or local model (Ollama, vLLM, OpenAI, Anthropic)
  • ✓ Run built-in safety scenario packs or build your own versioned scenarios
  • ✓ Compare models and judges with matched deltas and uncertainty
  • ✓ Visualize results in a local web server or export a single self-contained HTML file
  • ✓ Rejudge saved runs with a different judge — no re-running the target

Explore results interactively

Spin up a local web server to explore scenario details, or export a single self-contained HTML file to share.

terminal 
$ uvx 'simpleaudit[visualize]' serve --results_dir ./my_audit_results
